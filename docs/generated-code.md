Names: `snake_case` → `PascalCase` (`author_id` → `AuthorId`, `post_likes` → `PostLikes`).
Characters that cannot be in an identifier separate words (`in-progress` → `InProgress`).
Enum values that make poor names get one from [`EnumNames`](configuration).

`NOT NULL` columns get the tag `validate:"required"` for
[go-playground/validator](https://github.com/go-playground/validator); nullable columns are pointers.

## queries.go

`DBTX` is the interface of `*pgxpool.Pool`, `*pgx.Conn` and `pgx.Tx`. Per table:

| Method                                         | SQL                                                       |
| ---------------------------------------------- | --------------------------------------------------------- |
| `AddPosts(ctx, arg, customQuery)`              | `INSERT` of every column except the primary key, `RETURNING` all |
| `UpdatePosts(ctx, arg, where)`                 | `UPDATE … SET` every column except the primary key + `where`, `RETURNING` all |
| `SelectPosts(ctx, where)`                      | `SELECT` all columns + `where`                            |
| `GetPosts(ctx, id, customQuery)`               | `SELECT … WHERE "id" = $1`                                |
| `DeletePosts(ctx, where)`                      | `DELETE` + `where`; an empty `where` is an error          |
| `CountPosts(ctx, where)`                       | `SELECT COUNT(*)` + `where`                               |
| `ExecuteQueryPosts(ctx, query, args...)`       | your parameterized query, rows scanned into `[]Posts`     |
| `ExecuteQueryRowPosts(ctx, query, args...)`    | your parameterized query, one row scanned into `Posts`    |

`where` is appended after a space: `"WHERE status = 'draft' ORDER BY id"`. Read [Security](security)
before passing anything but constants.

`Get…` and `ExecuteQueryRow…` return `pgx.ErrNoRows` when nothing is found.

### Things to know

- `Add` and `Update` send every column, so column defaults do not apply: set `CreatedAt` yourself or
  use `ExecuteQueryRow` with your own `INSERT`.
- `Update` returns the first updated row; with a `where` that matches nothing it returns `pgx.ErrNoRows`.
- `ExecuteQuery…` scans all columns of the table in table order. Select them in that order and cast
  enum arrays to `text[]`: `SELECT id, …, labels::text[] …`.
- Tables whose primary key is not the `PrimaryKey` column still get `Get`, which will fail at run time.
