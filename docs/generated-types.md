# Generated types

One file, `models.go`, marked `// Code generated by db2go2types. DO NOT EDIT.` and formatted with
`gofmt`. It imports only `time`, when needed. Complete output for a sample schema:
[`examples/blog`](https://github.com/pluhsoft/db2go2types/tree/main/examples/blog).

| Schema object        | Go                                                                    |
| -------------------- | --------------------------------------------------------------------- |
| enum `post_status`   | `type PostStatus string` and a constant per value: `PostStatusDraft`  |
| table `posts`        | `type Posts struct` with a field per column, in column order          |

## Names

`snake_case` → `PascalCase`: `author_id` → `AuthorId`, `post_likes` → `PostLikes`.
Characters that cannot be in an identifier separate words (`in-progress` → `InProgress`);
a name starting with a digit gets the prefix `X`. Enum values that make poor names get one from
[`EnumNames`](configuration): `-enum-name '#A6D2FF=Blue'` gives `LabelColorBlue`.

When two names map to the same Go name (a table `status` and an enum `status`, columns `user_id`
and `userId`) the generator stops with an error instead of writing code that does not compile.

## Tags

`NOT NULL` columns get `validate:"required"` for
[go-playground/validator](https://github.com/go-playground/validator); nullable columns are pointers.

## Reading rows

Fields follow the column order, so `pgx.RowToStructByPos` works with `SELECT *`:

```go
rows, err := conn.Query(ctx, `SELECT * FROM blog.authors`)
authors, err := pgx.CollectRows(rows, pgx.RowToStructByPos[models.Authors])
```

pgx does not know enum array types, so select them as `text[]`:

```go
rows, err := conn.Query(ctx, `SELECT id, author_id, title, status, labels::text[], tags FROM blog.posts`)
```

## Diagram

With `-diagram docs/db.md` the generator writes a Mermaid class diagram: a class per table and an arrow
per foreign key column. GitHub and most Markdown viewers render it.
